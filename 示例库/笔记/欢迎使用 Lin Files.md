# 欢迎使用 Lin Files 🗂️

这是一个**本地「Obsidian 式」文件管理器**，管理的都是磁盘上的真实文件——在这里编辑保存，其他软件立刻可见。

> 提示：「示例库」只是随包附带的演示库，右键它 → 移除即可（不会删除磁盘文件）。

## 库（Vault）是什么

- 一个「库」就是磁盘上的一个普通文件夹，添加进来后即可在侧栏切换浏览
- 可以同时添加多个库；移除库只是从列表里拿掉，文件原样保留
- 库内支持多级文件夹、拖拽移动、重命名、删除（进系统回收站）
- 覆盖保存的文件会自动留带时间戳的历史版本，可随时从「历史版本」还原

## 你可以做什么

- 📝 **Markdown 笔记**：点右上角「编辑」，`Ctrl+S` 保存
- 🃏 **角色卡 / 世界书 / 聊天记录**：`卡与记录` 里的 json / jsonl 双击即可预览编辑
- 🖼️ **图片直览**：双击 png / jpg / gif / svg 直接看
- 🌐 **HTML 预览**：双击网页文件直接渲染，可切回源码
- 🗜️ **ZIP / .thm 直读**：双击压缩包列出内部清单，点 `theme.json` 看内容，还能一键解压
- 🔍 **全文搜索**：`Ctrl+Shift+F`，文件名和内容一起搜
- ⚡ **快速打开**：`Ctrl+P`，输入文件名回车直达
- 🧩 **内嵌工具**：主界面的工具栏可打开内嵌的 Lin Thm 预览器（.thm 主题实时预览）与 LinWork Pro（角色卡/世界书编辑器）

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+P` | 快速打开 |
| `Ctrl+Shift+F` | 全文搜索 |
| `Ctrl+S` | 保存 |
| `Alt+W` | 关闭当前标签 |
| `F2` | 重命名选中的文件 |
| `Delete` | 删除（进回收站） |
